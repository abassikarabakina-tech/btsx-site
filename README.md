# bts x — Personal Landing Page

This is the personal landing page for "bts x" (Taejay / TJ / Abbas).

Quick start:
1. Replace placeholder links in `index.html`:
   - Instagram, YouTube, Twitch links
   - Replace `VIDEO_ID` in the YouTube iframe with your video ID
   - Replace `you@example.com` with your email or newsletter link

2. Test locally:
   - Open `index.html` in your browser.

3. Deploy:
   - GitHub Pages: push files to a `username.github.io` repo or any repo and enable Pages on the default branch.
   - Netlify: drag-and-drop the folder to Netlify or connect the GitHub repo and deploy.
   - Vercel: import the repo and deploy (works with static HTML).

What to edit next:
- Change texts (hero, about, rules) to match your voice.
- Swap the YouTube embed with a Shorts or Reel link (YouTube short embed also works).
- Replace the simple mailto form with a real newsletter (Mailchimp, Buttondown) or a Google Form.
- Add social proof (snapshots of your top posts) or a small gallery.

Tips:
- Keep videos short and personal (30–60s) while building confidence.
- Use natural window light and clear audio for best results.
- Update your bio as you grow (add milestones, new links).

You can now publish this as "bts x" and start sharing the link.
